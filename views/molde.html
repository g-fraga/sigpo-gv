Início Praias e postos Segurança Área da equipe Sobre o projeto

SIGPO-GV Web é um trabalho de Gustavo Fraga para a disciplina Prática de Programação Web (Análise e Desenvolvimento de Sistemas, FMP). Código no GitHub. Praias e postos seguem uma lista levantada pelo autor, com posições aproximadas no mapa. Pessoas, escalas, horários e números de efetivo são fictícios e servem só para demonstrar o sistema. Não use este site para decidir se é seguro entrar no mar: siga a orientação dos guarda-vidas no local.
